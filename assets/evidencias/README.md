# Prints manuais da entrega

Salve nesta pasta as 15 capturas PNG listadas em [Prints da versão final](../../README.md#prints-da-versão-final). Use exatamente os nomes indicados; os links do README principal abrirão os arquivos depois do commit e push.

Esta pasta começa somente com estas instruções. Os prints ainda não foram incluídos. Não renomeie JPG para PNG sem exportar a imagem no formato correto, nem crie imagens vazias para simular comprovação.

As evidências automáticas anteriores ficam em `docs/evidence`; os testes não escrevem nesta pasta. Links de vídeo e Figma devem ser preenchidos no README principal. Depois de conferir as capturas e o acesso do professor, marque as pendências correspondentes no [checklist](../../docs/CHECKLIST-ENTREGA.md).
