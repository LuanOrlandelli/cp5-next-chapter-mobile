# Prints manuais da entrega

Salve nesta pasta as 15 capturas PNG listadas em [Prints da versão final](../../README.md#prints-da-versão-final). Use exatamente os nomes indicados; os links do README principal abrirão os arquivos depois do commit e push.

Os 15 prints foram incluídos pelo grupo e conferidos em 04/10/2026. Para atualizar as evidências, substitua o PNG correspondente e faça commit/push. Não renomeie JPG para PNG sem exportar a imagem no formato correto, nem crie imagens vazias para simular comprovação.

O código da venda da Prada corresponde aos prints do Perfil, dos detalhes e da tabela `sales`; a troca da Speedy corresponde a `exchanges`. O print do Storage usa outro envio de teste, identificado no README principal. O formulário foi capturado sem preenchimento, e o checkout está com crédito desativado. O vídeo final pode complementar a demonstração de preenchimento, envio e compra com crédito.

As evidências automáticas anteriores ficam em `docs/evidence`; os testes não escrevem nesta pasta. Links de vídeo e Figma devem ser preenchidos no README principal. Depois de conferir as capturas e o acesso do professor, marque as pendências correspondentes no [checklist](../../docs/CHECKLIST-ENTREGA.md).
